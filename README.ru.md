# ecos — симулятор мира на COBOL и Rust

**Языки:** [English](README.md) · **Русский**

Исторический «песочный» симулятор, в котором **COBOL (1959)** считает противоречия
капитализма, а **Rust (2015)** рисует их в TUI-интерфейсе. Модель построена на
марксистской политической экономии: стоимость создаётся трудом, классы конфликтуют,
способы производства сменяют друг друга через накопление и революцию, империи
поднимаются и падают на собственных внутренних противоречиях.

Цель проекта — **наблюдение**, не управление. Никакого «игрока» в привычном
смысле — ты смотришь, как мир разворачивается год за годом, и читаешь хронику.

> **Мета-ирония**: язык, созданный в конце 1950-х для капиталистического бухучёта
> (зарплатные ведомости, накладные, batch-обработка), считает структурные
> противоречия системы, которая его и породила.

## Что симулятор делает

`ecos` симулирует небольшой мир из **10 географических регионов** (рельеф, климат,
соседи — *базис*, не меняется) и до **30 политий** (государства, общины,
сообщества — *политическая надстройка*, всегда меняется). Каждый ход полития
производит стоимость, торгует с соседями, переживает классовое напряжение,
ведёт войны, накапливает капитал и, возможно, переходит к следующему способу
производства, коллапсирует или распадается на наследников.

Хроника фиксирует все события:

```
0083 WAR-START      Goldgate            Cassio of Goldgate strikes Saltmere.
0091 MODE-SHIFT     Frostfen            Slave -> Feudal. Manorial order replaces antiquity.
0127 INNOVATION     Embervast           Printing press! Ideas multiply.
0238 REVOLUTION     Stonehold           Artisans seize means of production. New order.
0312 FRAGMENT       Neo-Goldgate        Empire fragments. New polity rises in its lands.
0731 EXTINCT        Cinderkeep          Polity ceases to exist. Region falls silent.
```

Ты листаешь таблицу регионов, переключаешься между ними, смотришь на
sparkline-графики напряжения / населения / капитала, открываешь древо
технологий, наблюдаешь рынок и кризисы.

## Архитектура

```
┌────────────────────────────────────────────────────────────┐
│                       Rust (TUI / драйвер)                 │
│  • ratatui + crossterm  •  игровой цикл                    │
│  • парсит regions.dat / polities.dat / tech.dat / …        │
│  • рендерит таблицу, detail-панель, sparkline'ы, tech tree │
└──────────────────────────┬─────────────────────────────────┘
                           │  std::process::Command
                           ▼
┌────────────────────────────────────────────────────────────┐
│                     COBOL (движок)                         │
│  • cobol/world.cob     — генератор мира (один раз)         │
│  • cobol/simulate.cob  — один ход                          │
│  • точная десятичная арифметика (PIC 9V99) — экономика     │
│  • LINE SEQUENTIAL файлы = персистентный стейт             │
└────────────────────────────────────────────────────────────┘
```

**Двухпроцессная архитектура:** Rust никогда не меняет стейт мира напрямую.
Он запускает COBOL-бинарь `simulate` как subprocess раз в ход и потом
перечитывает результат из `.dat` файлов. Это держит симуляцию детерминированной,
независимо тестируемой и верной духу того, как работали мейнфрейм-batch-задачи.

**Файлы данных (в `cobol/`):**

| Файл | Описание |
|---|---|
| `regions.dat` | 10 строк × 61 байт — география (имя, рельеф, климат, основной товар, соседи). Статика; пишется один раз `world.cob`. |
| `polities.dat` | 30 строк × 164 байт — политика (mode, классы, правитель, capital, культура, возраст эпохи, region_id). Перезаписывается каждый ход. |
| `tech.dat` | 10 строк × 24 байта — прогресс исследований политии, 4 ветви × 4 уровня. |
| `relations.dat` | матрица 10×10 — дипломатические отношения (−100..+100). |
| `market.dat` | 8 товаров — глобальные supply, demand, цена, флаг кризиса. |
| `chronicle.dat` | append-only лог событий. |
| `year.dat` | номер текущего хода. |

## Один ход симуляции

Каждый вызов `cobol/simulate` обрабатывает один ход (один игровой год):

```
1.  TICK-MODE-YEARS    — у каждой живой политии растёт счётчик «возраст эпохи»
2.  PRODUCE            — труд × эффективность = стоимость (Маркс: value = labour time)
3.  MARKET             — агрегация supply / demand / цен по 8 товарам
4.  CHECK-CRISIS       — перепроизводство → обвал цен, флаг кризиса
5.  TRADE              — обмен с соседями, обновление trade balance
6.  WAR-CHECK / RESOLVE — 4 типа триггеров (см. ниже), разрешение в 3 года
7.  DISTRIBUTE         — wage fund ↔ потребление; голод при недостатке
8.  DEMOGRAPHY         — рост / убыль населения; collapse / rebirth / extinct
9.  CLIMATE-EVENTS     — terrain-specific опасности
10. CONSCIOUSNESS      — классовое сознание медленно дрейфует (Маркс)
11. CLASS-DRIFT        — крестьяне ↔ ремесленники ↔ торговцы ↔ аристократия
12. SOCIAL             — пересчёт классового напряжения от нормы эксплуатации
13. REVOLUTION         — если tension × consciousness прорывает — правящий класс падает
14. ACCUMULATE         — capital → mode-shift (органический путь смены формации)
15. TECH-RESEARCH      — 4 ветви, развилки на L3, sub-tech на L4
16. CULTURE-DRIFT      — векторы военной / торговой / религиозной культуры
17. INNOVATION-CHECK   — редкие одноразовые изобретения
18. CALC-MILITARY      — пересчёт военной силы
19. AGE-RULERS         — правители стареют, могут умереть, наследование
20. RELATIONS-DECAY    — дипломатическая память постепенно стирается к нулю
```

## Способы производства

Марксистская лестница, 8 ступеней:

| Способ | Эффективность × 1000 | Заметки |
|---|---|---|
| `PRIMITIVE` | 400 | Родовое общество, ритуальная культура (Энгельс) |
| `SLAVE` | 750 | Ранние города-государства, рабовладение |
| `FEUDAL` | 1000 | Манориальный базис |
| `MERCANTILE` | 1100 | Торговый капитал |
| `PROTO-INDUSTRL` | 1375 | Мануфактура, ранние фабрики |
| `INDUSTRIAL` | 1700 | Наёмный труд как доминанта |
| `IMPERIAL` | 2200 | Финансовый капитал, монополии (Ленин) |
| `SOCIALIST` | 1900 | Рабочие контролируют средства производства |

Плюс два «бездействующих» состояния: `COLLAPSED` (тёмные века, восстановление
через 8 ходов) и `EXTINCT` (исчезла навсегда).

**Два пути между формациями:**

- **Органический / накопительный** (`ACCUMULATE-ALL`): порог капитала + классовый
  состав + культурный множитель → вероятностный переход.
- **Революционный** (`REVOLUTION`): при прорыве `tension × consciousness`
  правящий класс падает, способ производства поднимается на ступень. Slave →
  Feudal (artisans + merchants ≥ 20%), Mercantile → Proto-Industrial (artisans
  ≥ 25%), Proto-Industrial → Industrial (artisans ≥ 30%), Imperial → Socialist.
  Industrial → Imperial **намеренно не** делается революцией — империализм по
  Ленину является органическим итогом концентрации финансового капитала, а
  не классовым прорывом.

## Жизненный цикл политии

```
                    ┌───── REBIRTH (8 ходов) ─────┐
                    ▼                             │
    ALIVE ─────► COLLAPSED ───► EXTINCT (слот сохраняет имя территории)
      │                          ▲
      ├──── pop < 20k на коллапсе ┘
      │
      ├──── pop 20–69k на коллапсе ──► COLLAPSED → REBIRTH
      │
      └──── pop ≥ 70k на коллапсе ──► FRAGMENT
                                       │
                                       └► родитель → EXTINCT
                                          наследник spawn'ится в том же регионе
                                          (Neo-<имя территории>, ⅓ pop, ¼ capital,
                                          новый правитель, FEUDAL, свежее сознание)
```

Это значит, что **государства реально могут умереть**. Карта может лишаться
населения. Империи могут распадаться на государства-наследники с новыми
именами («Neo-Ironmarch», «Neo-Goldgate») — как Римская империя распадалась
на пост-римские королевства.

## Войны

Четыре типа, у каждого — своя структурная причина:

| Тип | Триггер | Марксистское прочтение |
|---|---|---|
| `DYNASTIC` | капитал > 8 000, внутри спокойно, сосед ослаблен | Аристократия расширяет накопление, когда внутренние возможности исчерпаны. |
| `CRISIS` | перепроизводственный кризис + tension > 60 | Война как выход из кризиса: уничтожает «излишнее» производство, занимает безработных, переключает гнев масс наружу. |
| `IMPERIAL` | mode ≥ INDUSTRIAL + торговый баланс < −500 | Стадия Ленина: капитал должен расширяться или загнивать. |
| `CLASS` | классовое напряжение ≥ 90 + nobility > 5 | Внутренние репрессии — правящий класс силой давит растущее сознание. |

Войны разрешаются за 3 года. Победители забирают 30% капитала проигравшего,
часть рабочей силы (15% часов труда), могут выгрести один тех, и подталкивают
проигравшего ближе к коллапсу.

## Древо технологий

**4 ветви × 4 уровня = 16 ячеек у политии, 44 разные технологии, 1296 возможных
идентичностей.**

| Ветвь | Тема | L1 / L2 / L3 альтернативы / L4 sub-tech |
|---|---|---|
| `prod` | Производство | Bronze / Iron / Steam, Forging, Hydraulics / 6 sub |
| `org` | Организация | Coinage / Banking / Joint-Stock, Cooperatives, Cartels / 6 sub |
| `know` | Знание | Writing / Printing / Empiricism, Scholasticism, Folk Wisdom / 6 sub |
| `pow` | Власть | Standing Army / Bureaucracy / Mass Conscription, Prof. Army, Militia / 6 sub |

Скорость исследования зависит от способа производства, совпадения с рельефом,
доли профильного класса, выбора L3-альтернативы в KNOW и **культурного
множителя** (диапазон ~0.33×–2.33×). Технологии могут также распространяться
через диффузию (если у соседа уровень выше на 1) или быть награблены в войне.

## Культура и сознание

Два разных понятия, часто путаемых в популярной политтеории:

- **Культура** — это *мировоззрение*. Три вектора у политии, 0..100: `mil`
  (милитаристский), `merc` (коммерческий), `rel` (религиозный). Растут от
  трейтов правителя, способа производства, влияния соседей; сами по себе
  постепенно затухают к нулю. Культура **множит** вероятность mode-shift'а
  (Маркс: надстройка обратно влияет на базис) — без коммерческой культуры
  переход FEUDAL → MERCANTILE происходит вяло даже при накопленном капитале.
- **Классовое сознание** — это *осознание структурной эксплуатации*. Растёт
  только при наличии активного рабочего класса (artisans + merchants ≥ 30%) —
  в крестьянских обществах остаётся на нуле. PROTO-INDUSTRIAL и далее питают
  его медленно (~1/ход). Decay'ит без active классовой борьбы (−1 каждые 5
  ходов). Это **множитель** в вероятности революции: tension даёт давление,
  сознание — восприимчивость.

## Установка

### Требования

- **GnuCOBOL 3.x** (`cobc`). На macOS: `brew install gnu-cobol`. На Debian/
  Ubuntu: `apt install gnucobol`.
- **Rust 1.70+** с `cargo`.
- Терминал с поддержкой truecolor и unicode (большинство современных).

### Сборка

```bash
make           # собирает COBOL-бинари + Rust release одной командой
# Или явно:
make cobol     # cobc -x -free cobol/{world,simulate}.cob
cargo build --release
```

### Запуск

```bash
cargo run --release
```

Откроется стартовое меню — выбери **New game**, загрузи слот или выйди. Затем
основное представление: таблица из 10 регионов с текущими хозяевами, detail-
панель справа, рынок, лента хроники, footer с keybinds.

## Сохранения

Пять фиксированных слотов в `saves/slot1..5/`. Каждый — снимок всех `.dat`
файлов. Сохранения явные: выход без `S` теряет прогресс. Стартовое меню
показывает год для каждого занятого слота. Старые сейвы single-file
`world.dat` автоматически мигрируются в новый формат `regions.dat` +
`polities.dat` при первой загрузке.

## Детерминизм и регрессия

`FUNCTION RANDOM(seed)` в GnuCOBOL детерминирован при фиксированной
последовательности вызовов. Seed устанавливается раз в ход из текущего года.
Это значит **одинаковый вывод world.cob + одинаковое число ходов = байт-в-байт
одинаковый chronicle.dat**.

`scripts/baseline.sh capture | check` использует это для регрессионного
тестирования: фиксирует 500-ходовой baseline, потом проверяет что любой
будущий запуск всё ещё совпадает. Используется во время рефакторинга для
доказательства что структурные изменения не сдвигают поведение.

## Теоретическая основа

Симуляция опирается на классическую и современную марксистскую теорию.
Ничего из этого не зашито как идеология — это *механизм*, по которому
двигаются числа:

- **Маркс**, *Капитал*: трудовая теория стоимости, прибавочная стоимость,
  кризисы перепроизводства, первичность базиса над надстройкой.
- **Энгельс**, *Происхождение семьи*: ритуально-родовая первобытная культура
  как стартовая точка, не «чистый лист».
- **Ленин**, *Империализм*: концентрация финансового капитала производит
  имперскую стадию; неравномерность развития регионов.
- **Троцкий**: культурная диффузия — механизм, через который менее
  развитые регионы перенимают элементы у более развитых соседей.
- **Дэн Сяопин**: производительные силы первичны; культура модулирует
  скорость, но не блокирует переход.
- **Си Цзиньпин** («культурная уверенность»): культура обратно влияет на
  материальный базис — гордая традиция знания умножает скорость науки.
- **Ван Хуэй**: множественность модернити — каждая полития ищет свой путь
  по лестнице способов производства, нет единого линейного марша.

## Дорожная карта

Проект построен **фазами**, каждая — сфокусированное расширение с
регрессионной проверкой. Полная история — в [`DEVLOG.md`](DEVLOG.md).
Основные вехи:

- **Phases 1–6** — генератор, базовая экономика, военная механика, TUI.
- **Phase 9** — правители как именованные личности с чертами характера.
- **Phase 10** — демография в движении, миграция беженцев при коллапсе.
- **Phase 11** — полная 7-ступенчатая лестница способов + империалистическая
  война.
- **Phases 13–18** — древо технологий (4 × 4, развилки альтернатив, sub-tech).
- **Phases 19, 22, 23** — естественный темп эпох через культурную уверенность
  и трудовое сознание; революция как путь смены формации.
- **Phase 20** — save / load, стартовое меню.
- **Phase 21** (частично откачена) — явные минимумы длительности эпох.
- **Phase 24 / Этап 1** — расщепление `Region` (география) от `Polity`
  (политика).
- **Phase 24 / Этап 2A** — `EXTINCT` mode для малых политий (государства
  могут умирать навсегда).
- **Phase 24 / Этап 2B** — 30 слотов политий; коллапс крупной политии через
  `FRAGMENT` рождает наследника в том же регионе с именем «Neo-X».

**Запланировано:**

- **Phase 24 / Этап 2C** — `STATELESS` mode для племенных общин; spawn в
  соседних vacant регионах; беженцы как зерно нового сообщества.
- **Phase 24 / Этап 2D** — 3 ячейки на регион (мозаика); территориальная
  аннексия в войне.
