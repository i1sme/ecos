## Концепция

Процедурный генератор мира и экономическая симуляция в духе Dwarf Fortress,
реализованные на двух языках с намеренным архитектурным диссонансом:

- **COBOL (1959)** — мозг: хранит мировой стейт, считает экономику, генерирует мир
- **Rust (2015)** — тело: игровой цикл, пользовательский ввод, TUI-интерфейс

Социо-экономическая симуляция построена на **марксистской политической экономии**.
Стоимость создаётся трудом. Классовые противоречия движут историей.
Кризисы и войны — не случайность, а структурная неизбежность.

Мета-ирония проекта: язык созданный для капиталистического бухучёта
считает противоречия самого капитализма.

## Архитектура

```
┌─────────────────────────────────────────────────────┐
│                     RUST (main)                     │
│  • Игровой цикл (turn-based)                        │
│  • Пользовательский ввод                            │
│  • TUI через ratatui                                │
│  • Парсинг мирового стейта из world.dat             │
│  • Летопись событий из chronicle.dat                │
└──────────────────┬──────────────────────────────────┘
                   │ subprocess
                   ▼
┌─────────────────────────────────────────────────────┐
│                    COBOL (engine)                   │
│  • world.cob    — генерация мира                    │
│  • simulate.cob — симуляция одного хода             │
│  • Точная десятичная арифметика (PIC 9Vnn)          │
│  • Запись стейта в world.dat / chronicle.dat        │
└─────────────────────────────────────────────────────┘
```

Rust запускает COBOL через `std::process::Command`.
COBOL пишет `world.dat`, Rust читает и рендерит.
Каждый ход: Rust → запуск simulate.cob → чтение результата.

## Марксистская основа симуляции

### Трудовая теория стоимости

Единица стоимости — **рабочий час (WS-LABOUR-HOURS)**.
Стоимость товара = рабочие часы × производительность средств производства.
Торговля — это обмен овеществлённым трудом. Регион с примитивными орудиями
отдаёт больше труда за тот же товар чем регион с развитыми средствами производства.

### Прибавочная стоимость

`WS-SURPLUS-RATE` — доля произведённой стоимости которую правящий класс изымает.

```
Необходимый труд  → воспроизводство рабочей силы (еда, жильё)
Прибавочный труд  → накопление капитала правящего класса
```

Высокая норма → быстрое накопление + быстрый рост классового напряжения.

### Классовая структура регионов

| Класс        | Поле COBOL          | Роль                                    |
|--------------|---------------------|-----------------------------------------|
| Крестьяне    | WS-PEASANTS-PCT     | Основной труд, еда, сырьё               |
| Ремесленники | WS-ARTISANS-PCT     | Переработка, инструменты                |
| Торговцы     | WS-MERCHANTS-PCT    | Торговые маршруты, скорость обмена      |
| Аристократия | WS-NOBILITY-PCT     | Изъятие ренты, военная сила             |
| Духовенство  | WS-CLERGY-PCT       | Легитимация строя, снижение напряжения  |

### Способы производства

```
PRIMITIVE → FEUDAL → MERCANTILE → PROTO-INDUSTRIAL
```

Переход происходит когда материальные условия созревают:
достаточно капитала + технологий + классового напряжения.

### Классовое напряжение

`WS-CLASS-TENSION PIC 9(3)` — накапливается от эксплуатации, голода,
неравенства, кризисов. При достижении порогов:

```
0–39   → Stable     (стабильность)
40–69  → Unrest     (волнения, -10% производительность)
70–89  → Strike     (забастовки, торговля прерывается)
90–99  → Revolt     (восстание, аристократия теряет контроль)
100    → REVOLUTION (смена класса у власти, новый способ производства)
```

### Кризис перепроизводства

Если предложение товара превышает спрос — цены рушатся, прибыль исчезает,
безработица растёт, напряжение ускоряется. Структурная неизбежность,
а не случайное событие. Триггер для военной агрессии (см. ниже).

## Механика войн

Войны не случаются произвольно — они вытекают из структурных противоречий.
Каждый тип войны имеет конкретные триггеры и последствия.

### Типы войн

**1. Война правящих классов (Dynastic War)**
Аристократия нападает на соседа ради земли и рабочей силы.
Это рациональная стратегия накопления когда внутренние возможности исчерпаны.

```
Триггер:
  WS-CAPITAL-STOCK > 8000        (есть ресурсы на войну)
  AND WS-CLASS-TENSION < 50      (внутри стабильно)
  AND сосед: WS-CLASS-TENSION > 70  (сосед ослаблен)

Последствия победы:
  + захват части WS-CAPITAL-STOCK соседа
  + аннексия WS-LABOUR-HOURS (рабочая сила)
  + рост WS-SURPLUS-RATE у победителя (больше эксплуатации)
  + рост WS-CLASS-TENSION у победителя +15 (война дорого стоит)

Последствия поражения:
  - потеря капитала
  - резкий рост WS-CLASS-TENSION (поражение = кризис легитимности)
```

**2. Империалистическая война (Imperial Expansion)**
Меркантильные и proto-industrial регионы захватывают рынки и источники сырья.
Ленинская стадия: капитал вынужден расширяться или загнивать.

```
Триггер:
  WS-PROD-MODE = "MERCANTILE" OR "PROTO-INDUSTRL"
  AND WS-TRADE-BALANCE < -500    (дефицит торгового баланса)
  AND сосед имеет нужный ресурс которого нет у агрессора

Последствия победы:
  + монополия на ресурс соседа
  + принудительная торговля по невыгодным ценам
  + WS-PROD-MODE соседа откатывается на один уровень назад
```

**3. Классовая война (внутренняя репрессия)**
Не между регионами — внутри. Аристократия применяет военную силу
против нарастающего восстания.

```
Триггер:
  WS-CLASS-TENSION >= 90
  AND WS-NOBILITY-PCT > 5        (аристократия ещё у власти)

Результат A — репрессия удалась:
  WS-CLASS-TENSION -= 30
  WS-PEASANTS-PCT -= 5           (уничтожение наиболее активных)
  WS-LABOUR-HOURS *= 0.90        (потеря рабочей силы)

Результат B — репрессия провалилась (если WS-CLASS-TENSION = 100):
  → REVOLUTION: аристократия теряет власть
  WS-NOBILITY-PCT = 0
  WS-ARTISANS-PCT или WS-MERCHANTS-PCT берут власть
  WS-SURPLUS-RATE снижается
  WS-PROD-MODE может перейти на следующую стадию
```

**4. Война как выход из кризиса (Crisis War)**
Классический механизм: кризис перепроизводства → безработица →
правящий класс инициирует войну чтобы уничтожить "лишнее" производство,
занять безработных в армии и переключить классовое напряжение вовне.

```
Триггер:
  WS-CRISIS-FLAG = 1             (кризис перепроизводства)
  AND WS-CLASS-TENSION > 60      (внутреннее давление)
  AND WS-CAPITAL-STOCK > 3000    (ресурсы на войну)

Последствия:
  WS-CLASS-TENSION -= 20         (внешний враг отвлекает)
  WS-LABOUR-HOURS *= 0.85        (часть рабочих в армии)
  WS-OUTPUT-VALUE *= 0.80        (производство падает — кризис "решён")
  chronicle: запись о войне
```

### Поля для военной механики (добавить в WS-REGION)

```cobol
   10 WS-MILITARY-STRENGTH  PIC 9(5).    *> военная сила (функция от капитала)
   10 WS-AT-WAR-WITH        PIC 99.      *> индекс противника (0 = мир)
   10 WS-WAR-YEAR           PIC 9(3).    *> сколько лет идёт война
   10 WS-WAR-TYPE           PIC X(10).   *> DYNASTIC/IMPERIAL/CLASS/CRISIS
```

### Военная сила

```
WS-MILITARY-STRENGTH = (WS-CAPITAL-STOCK / 10)
                      × (WS-NOBILITY-PCT / 100 × 3)
                      × (100 - WS-CLASS-TENSION) / 100
```

Высокое классовое напряжение ослабляет армию — солдаты не хотят воевать
за правящий класс когда сами голодают. Это прямо из Ленина.

## Логика симуляции одного хода (simulate.cob)

```
1. PRODUCE       — стоимость через трудовые часы
2. MARKET        — агрегация спроса/предложения, пересчёт цен
3. TRADE         — обмен между соседями
4. WAR-CHECK     — проверить триггеры всех типов войн
5. WAR-RESOLVE   — разрешить текущие войны (победа/поражение/продолжение)
6. DISTRIBUTE    — зарплатный фонд → потребление
7. SOCIAL        — пересчёт классового напряжения
8. REVOLUTION    — если TENSION = 100
9. ACCUMULATE    — капитал → производительность → переход способа производства
10. CHRONICLE    — запись всех событий
```

## Шпаргалка

### Марксистские концепции
- **Трудовая стоимость**: ценность = рабочие часы × производительность
- **Прибавочная стоимость**: изъятие сверх необходимого труда
- **Накопление**: прибавочная стоимость → средства производства
- **Классовое противоречие**: интересы классов структурно несовместимы
- **Исторический материализм**: способ производства определяет всё остальное
- **Кризис перепроизводства**: структурное следствие конкуренции
- **Империализм**: высшая стадия, капитал вынужден расширяться

### COBOL
- `PIC X(n)` — строка n символов
- `PIC 9(n)V99` — точное десятичное (без потерь — важно для экономики!)
- `PIC S9(n)V99` — знаковое (торговый баланс, может быть отрицательным)
- `OCCURS n TIMES` — массив
- `FUNCTION RANDOM` — псевдослучайное 0..1
- `PERFORM VARYING` — цикл
- `WRITE RECORD` — запись в файл
- `SELECT ... ASSIGN TO` — привязка файла

### Rust
- `std::process::Command` — запуск COBOL subprocess
- `BufReader` + срезы `&str` — парсинг fixed-width без аллокаций
- `ratatui` — TUI виджеты (таблицы, цвета, layout)
- `crossterm` — backend для macOS
